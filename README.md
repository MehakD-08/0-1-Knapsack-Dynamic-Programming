Activity on 0-1 knapsack

Read test cases separated by lines starting with #Test.

For each test case, extract:

Number of items n  

Capacity W

First line : n W

Weights and values.

Subsequent lines: Weights and values

Compute the maximum total value using the 0/1 Knapsack dynamic programming algorithm.

Print the result for each test case.

Store all the test results in a new file named result.txt.

Format: #Test case input (n w)  test result

  Create a live ASCII visualization of the 0/1 Knapsack dynamic programming table as it builds step-by-step. Share the github link also.
